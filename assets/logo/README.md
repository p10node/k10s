# k10s logo

The mark is a **ship's helm wheel with a mouse pointer clicking its rim** - the
Kubernetes helm (the `⎈` in the README) plus the one thing no other cluster TUI
puts on screen: a cursor. It says the whole positioning in one glyph, *the
Kubernetes terminal UI you can click*.

The wordmark spells `k10s` with the wheel standing in for the `0`, so mark and
wordmark are the same drawing at two scales.

Every file here is generated by [generate.py](generate.py) - do not hand-edit
the SVGs. Change the numbers in the script and run:

```sh
just logo          # SVGs + all PNG exports (needs python3 + rsvg-convert)
```

## Which file to use

| File | Use for |
|---|---|
| `wordmark-on-dark.svg` · `wordmark-on-light.svg` | READMEs, docs headers, sites - the default lockup |
| `wordmark-mono.svg` | one-colour contexts; inherits `currentColor` |
| `mark.svg` | app icon / avatar - ships its own rounded dark tile |
| `mark-on-dark.svg` · `mark-on-light.svg` | mark alone on a background you control |
| `mark-mono.svg` | stickers, engraving, single-colour print |
| `favicon.svg` (+ `favicon-16/32/48/180.png`) | tabs and touch icons - simplified: no handle nubs, fatter strokes |
| `social-preview.png` | GitHub repo social preview (1280×640, Settings → Social preview) |
| `mark-64…1024.png` | raster fallbacks where SVG is not accepted |

`favicon.svg` is a deliberately different drawing: at 16 px the seven handle
nubs turn to mud, so that variant drops them and thickens everything.

## Rules

- **Clear space:** keep at least the height of the wheel's hub on every side.
- **Minimum sizes:** wordmark 120 px wide, mark 32 px, below that use `favicon.svg`.
- **The cursor always stays on the lower-right of the wheel.** It is not
  decoration - it is the differentiator. Never remove it from the wordmark.
- Do not re-colour the gradient, outline the letters, add shadows, or set the
  wordmark in a substitute font: the letterforms are paths, not text.
- On busy photography or video, use `mark.svg` (it carries its own tile) rather
  than the transparent variants.
