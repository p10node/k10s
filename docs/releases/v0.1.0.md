**k10s — the Kubernetes terminal UI you can click.**

k9s taught us to live in the terminal. k10s makes that terminal
point-and-click, instantly searchable, themeable — and gives it an AI that
already knows your cluster, namespace and selected object.

First tagged release. Inspired by k9s, different philosophy and a much
smaller scope.

![k10s running in a terminal: resource sidebar, pod table with live status, and an action pane for the selected pod](https://raw.githubusercontent.com/p10node/k10s/v0.1.0/assets/screenshot.png)

## Install

```bash
go install github.com/p10node/k10s@latest
```

Or grab a binary below — macOS (Intel / Apple Silicon), Linux (amd64 /
arm64), Windows (amd64). One static binary, no dependencies.

No cluster to hand? `git clone https://github.com/p10node/k10s && cd k10s &&
go run .` drops straight into an offline demo backend, complete with a
CrashLoopBackOff to poke at. The same binary connects to a real cluster the
moment one is reachable — there is no flag to remember.

## What's in it

- **Your mouse works.** Click a row, click a pane, click `[ zoom ]`, click
  `ns default ▾`, scroll the table. Every border button is real.
- **Nothing hidden behind memorised keys.** The actions that apply to the
  object you selected are listed in their own pane, with the hotkey next to
  each one.
- **One search box for the whole cluster.** `ctrl+p` searches resource kinds
  *and* objects together. No prefix language to learn.
- **It opens instantly.** Startup registers zero watches and waits for
  nothing — informers start lazily, per kind, the first time you look at one.
  Opening Pods watches pods, not every Secret and Event you own.
  ([how, and the regression guards](https://github.com/p10node/k10s/blob/v0.1.0/docs/performance.md))
- **AI that can see the screen.** `ctrl+a`, ask in plain English. The current
  context, namespace, kind and selected object go into the prompt, so "why is
  this pod unhealthy?" means *this* pod. Bring your own key —
  OpenAI-compatible or Anthropic.
- **Logs, exec, port-forward.** Follow logs (`l`), a real interactive exec
  session with a resize-aware raw TTY (`s`), SPDY port-forward (`p`).
- **It updates itself.** `/update` installs the newest release over the
  running binary — checksum-verified, atomic, and it offers to restart into
  the new one. ([how](https://github.com/p10node/k10s/blob/v0.1.0/docs/update.md))
- **Seven themes**, previewed live before you commit, via `/theme`.
- **Copy mode.** `ctrl+s` releases the mouse so the terminal can select text —
  the only way to copy out of a mouse-capturing TUI.

## Known limits

Worth saying plainly, since this is a `v0.1.0`:

- **Not smoke-tested on a production cluster yet.** Read-heavy use is what it
  has seen. Treat destructive actions with the caution the version number
  suggests.
- **`checksums.txt` is not a signature.** It proves the download matches what
  this release published; it proves nothing about *who* published it. Signing
  with cosign is the fix, and it goes in before anyone should trust this
  anywhere that matters.
- **Windows is cross-compiled and lightly exercised.** Reports about exec and
  port-forward from Windows users are especially welcome.

## Verify a download

```bash
shasum -a 256 -c checksums.txt --ignore-missing
```
